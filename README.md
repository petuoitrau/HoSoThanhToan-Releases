# Hồ Sơ Thanh Toán

Bản phát hành WPF cho Windows x64, giao diện Liquid Glass.

[Tải bản mới nhất](https://github.com/petuoitrau/HoSoThanhToan-Releases/releases/latest)

Tải EXE để chạy hoặc giải nén ZIP chứa EXE và hướng dẫn. Không cần cài riêng .NET Desktop Runtime.

Trong ứng dụng: **Tiện ích → Kiểm tra cập nhật**, hoặc mở mục này trong Trợ giúp. Ứng dụng hiển thị tiến trình tải, kiểm tra SHA-256 và phiên bản trước khi mở bản mới; lưu và khôi phục hồ sơ đang làm. Bản từ 2.19.17 có hỗ trợ cập nhật trực tiếp.

Lịch sử, danh bạ và hồ sơ lưu trên máy người dùng. Kho này chỉ phân phối ứng dụng và hướng dẫn, không chứa mã nguồn, chứng từ hay dữ liệu người dùng.

Đối chiếu file tải bằng SHA256SUMS.txt trong từng bản phát hành.
